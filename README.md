# Dada and Surrealism: online module

A linked wiki on Dada and Surrealism: the movement, what led up to it, what followed, and its historical and social context.

- Start at the home page, then use the Explore page to filter notes by lens (historical, social, artist, medium), medium and note type.
- Notes are short and linked. Each link states its relationship in the text.
- Built with Quartz 5 (https://quartz.jzhao.xyz).
